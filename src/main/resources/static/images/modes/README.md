# Interface assets

The generic colored mode icons (online, bot, friend, puzzle, learn, history, rating) are local copies of the public Chess.com design-system SVGs, selected to fulfill the explicitly requested Chess.com reference. Source: https://assets-ds.chess.com/color-icons/ (time-blitz.svg, device-bot.svg, hand-shake.svg, puzzle-piece.svg, lessons.svg, board-archive.svg, leaderboard.svg). Retrieved from the rendered public /play page on 2026-11-07. Original rights remain with their respective owner.

checkers.svg is an original checkers-specific mark. No Chess.com logo is used. The two local Chess Sans heading fonts are from the same public page: https://www.chess.com/bundles/web/fonts/chess-sans/ChessSans-Bold.19a3983f.woff2 and ChessSans-ExtraBold.3b60f736.woff2. All runtime requests are local.

`home.svg` and `play.svg` are original navigation icons: a house for Home and a draughts board for Play. These replace repeated brand marks in both desktop and mobile navigation.
