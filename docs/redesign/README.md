# Редизайн Checkers Online

Проект: русские шашки 8×8, Spring Boot/Thymeleaf/vanilla JS, EN/RU/HY.

- Исходный аудит, семь реальных референсов, три концепции и спецификация: [design-plan.md](design-plan.md).
- Независимые заключения: [reviews](reviews).
- Начальная ветка: `main`, чистое рабочее дерево; точка отката `9e57959f1407f85690309ecca12cded8f68972bc`.
- Рабочая ветка: `codex/redesign-checkers`.

После первоначального ревью пользователь явно выбрал тёмное лобби ближе к своему референсу. Окончательное направление и финальная проверка будут отражены в итоговом отчёте; ранние светлые изображения являются промежуточными материалами, не финальным результатом.

Окончательная версия: [REPORT.md](REPORT.md), [тёмная спецификация](dark-direction.md), [сравнение](screenshots/comparison.png). Финальные6 независимых post-review verdict — APPROVED.
