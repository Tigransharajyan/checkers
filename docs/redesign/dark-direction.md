Материалы прежнего аудита и исследования: /tmp/checkers-redesign/design-review.md. Реализованные полезные сценарии и исправления остаются, смена направления не откатывает UX.

## Конкретная новая спецификация
- Сохраняем проверенную task-first структуру текущего лобби: компактный header, active games перед выбором, сгруппированные online/bot/friend actions слева, справа реальная daily puzzle. История внизу. На зарегистрированном аккаунте реальные total/wins/winrate переезжают в компактный aside ниже puzzle, без отдельного гостевого placeholder. Основные routes/DOM/hooks, game/grid/keyboard/overlays/forms сохраняются.
- Цвета: canvas #232522, surface #2D302B, surface-alt #363B32, sidebar #1B1E1A. Text #F1F3EA, secondary #D0D7C8, muted #BBC4B3. Divider #454D40, input boundary #7C8B71. Accent #A2C970, hover #B5DA83, active #8EB85C с ink #192313. Inverse CTA на зелёном online block #F1F3EA с #192313. Primary online block surface-alt с левой зелёной полосой и зелёной CTA (в отличие от прежнего заполненного pine panel), чтобы не создавать большой яркий hero.
- Success background #293B27/text #C5E3A6, error background #402A29/text #FFB9AC, danger action #8C302E/text #FFF4EC; quiet danger #FFB9AC. Warn bg #423B25/text #F2D997. Focus #D6EBAE, outline3px; на доске прежний dual outline.
- Board прежний #F0DFC0/#8B6245, white #FFFAEA black #17241F с структурным double rim, без теней/градиентов; это полезный тёплый противовес graphite. Favicon плоский, social diagram под новую dark палитру.
- Типографика: Inter/Noto Armenian для всего UI и бренда; h1 32/1.2 weight600 desktop, 28 mobile, HY28/26; h2 20/1.35, body16/1.55, captions14. Никаких serif/uppercase micro labels. Sidebar logo остаётся двумя шашками.
- Композиция: desktop sidebar208, max1184 content32px, main/asides gap24, aside300. Мodes открытые сгруппированные строки surface, padding20; без lift/тени/отдельного цвета каждому режиму. Corner6, input4. Более плотный игровой характер референса, без копирования шахматных карточек, таймеров/рейтинговELO/уроков, которых нет.
- Responsive/container/keyboard/state contracts v2 сохраняются. Цвет только у главных действий и смысловых состояний. Все страницы получают согласованную dark систему, не только home. No additional dependencies.

## Исправления post-review r1 уже внесены в source и требуют верификации
Backdrop исключён из inert siblings, но остаётся aria-hidden и не focusable. Game grid rows:auto 1fr устраняют разрыв. Переход от matchmaking к friend/bot/join отменяет очередь до запроса, stale callbacks проверяют client identity; cancellation failure запрещает создание нового режима. Task ACTIVE получает постоянный live announcement с реальными ходами/ответом чёрных, финальныйfeedback сохраняется. Заголовок rating теперь предметный «Как считается процент побед». HY date fallback и нейтральная подпись server count устраняют Nov6/1партий. Help screenshot будет viewport-only, не fullpage fixed artifact.
