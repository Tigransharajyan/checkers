# Доработка точности Chess.com

Дата: 2026-11-07. Продолжение запроса пользователя на точное соответствие публичным главной и /play Chess.com.

Референс лично открыт в браузере: https://www.chess.com/ и https://www.chess.com/play. У карточек /play измерены реальные размеры, градиент, тени и размеры иконок. Содержимое сайта остаётся про русские шашки, с собственным названием, реальными данными и EN/RU/HY.

## Изменения

- Главная: большая шашечная доска слева, крупный центрированный заголовок и две объёмные кнопки справа; отдельная ссылка на игру с другом, реальная статистика присутствия и сыгранных партий. Ниже — настоящая задача дня; продолжение партий, личная статистика и история сохранены.
- /play: доска с координатами и игроками, панель с собственной прокруткой, полноценные карточки-кнопки «Играть онлайн», «Играть с ботом», «Играть с другом», задачи и правила. Клик по всей карточке запускает соответствующее действие. Выбор сложности, создание/копирование/открытие приглашения и вход по коду сохранены.
- Общий интерфейс: размеры навигации, цветные SVG-иконки, начертания заголовков, градиенты и тени кнопок по референсу; собственный шашечный знак и объёмные шашки.
- Все ресурсы локальные. Происхождение иконок и шрифтов: `src/main/resources/static/images/modes/README.md`.
- Адаптивный слой: `src/main/resources/static/css/chess-layout.css`, подключён после существующих базовых стилей. Работающие движки, API и игровой JS не изменялись этой доработкой.

## Исправление устаревшего входа

После перезапуска локальной H2-базы сохранённый в браузере JWT мог ссылаться на отсутствующего пользователя. Исключение в JWT-фильтре приводило к 500 и бесконечному предупреждению о проверке входа. Теперь отсутствующий/заменённый пользователь не аутентифицируется; защищённые API возвращают 401, публичные запросы продолжают работать. Клиент удаляет только подтверждённо недействительную сессию, сохраняя вход при временных 500/сетевых сбоях. Одновременные запросы используют одно обновление токенов.

Проверки: 58 Java-тестов и 12 браузерных проверок прошли, включая новые сценарии отсутствующего пользователя, повторного ID и отклонённого сохранённого входа. Предупреждение в открытой вкладке после обновления не отображается.
